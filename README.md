# Prioritree
A task manager and address book for detailed and organised to-do lists for the short and long term.

This was a program I wrote in Python for my Computing A-Level in 2016, for which I won the Renishaw Computing Award at my school.

Currently you will need to have Python installed on your computer to run it (by opening Prioritree.pyw) but when I get round to completing the project I will create an .exe file.
